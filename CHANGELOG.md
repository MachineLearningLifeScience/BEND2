# Changelog

## 1.0.0 — 2026-11-02

Initial standalone release of BEND 2.0.

- Eight evaluation tasks spanning sequence priors, functional prediction,
  biological context, genetic interactions and genomic design.
- A Python model adapter, resumable inference and task-specific fitted readouts.
- Versioned datasets with size and SHA-256 verification, plus a bundled Atlas
  example that runs without downloading data or model weights.
- Results and prediction exports, contribution validation and maintainer rescoring.
- An interactive leaderboard with reference results and task explanations.
