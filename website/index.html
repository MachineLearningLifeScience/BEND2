A benchmark for
genomic design

Why?

There are far more ways to change a DNA sequence than we can test in the lab. Models could help us choose which changes to try, but we need to know how much we can rely on their suggestions.

BEND 2.0 was built around that question. We compare models using experimental measurements, including cases where the same edit behaves differently depending on the cell type or surrounding DNA. We want to understand when their predictions are useful for deciding what to test next.
